# UI / 画面設計書

## 1. デザインシステム

DESIGN.md で定義されたデザイントークンに従う。

### カラーパレット
| トークン | 値 | 用途 |
|---------|-----|------|
| `primary` | `#6c0c20` | メインボタン・強調 |
| `primary-container` | `#8b2635` | カードヘッダー背景等 |
| `on-primary` | `#ffffff` | primary 上のテキスト |
| `secondary` | `#8d4f00` | 補助ボタン・バッジ |
| `surface` | `#fcf9f8` | ページ背景 |
| `surface-container` | `#f0eded` | カード背景 |
| `on-surface` | `#1b1c1c` | 本文テキスト |
| `outline` | `#897172` | ボーダー |
| `error` | `#ba1a1a` | エラー表示 |

### タイポグラフィ
| クラス | フォント | サイズ | 用途 |
|--------|---------|--------|------|
| h1 | Noto Serif 700 | 48px | ページタイトル |
| h2 | Noto Serif 600 | 32px | セクション見出し |
| h3 | Noto Serif 500 | 24px | カード見出し |
| body-lg | Work Sans 400 | 18px | 本文（大） |
| body-md | Work Sans 400 | 16px | 本文（標準） |
| label-caps | Work Sans 600 | 12px | ラベル・バッジ |

### スペーシング
- ページ最大幅: `1280px`
- ページ左右マージン: `64px`（モバイルは `16px`）
- カードパディング: `24px`

## 2. 共通レイアウト

### ヘッダー
- ロゴ（左端）: "The sake of Sake" をクリックで `/` へ遷移
- ナビゲーション（中央〜右）: 「知識を探す」→ `/knowledge`
- 右端:
  - 未認証: 「ログイン」ボタン
  - 認証済み: ユーザーアバター（ドロップダウン）→「マイ記録」「ダッシュボード」「ログアウト」

### フッター
- コピーライト表記のみのシンプルなフッター
- カラー: `surface-container`

## 3. 画面別設計

### 3.1 トップページ（`/`）

**目的**: サービス紹介・ログイン・登録への誘導

**構成要素**:
1. **ヒーローセクション**
   - キャッチコピー: 「あなたの飲んだお酒を、記録しよう。」（h1）
   - サブコピー: サービス概要（body-lg）
   - CTA ボタン: 「記録を始める」→ `/signup`（primary）、「ログイン」→ `/login`（secondary）
   - 背景: お酒のビジュアル（淡いグラデーション）

2. **機能紹介セクション**（3カラムカード）
   - 「記録する」「学ぶ」「振り返る」の3機能を簡単に説明

3. **カテゴリプレビューセクション**
   - 5カテゴリのカードを横並び表示

---

### 3.2 ログイン画面（`/login`）

**目的**: 既存ユーザーのログイン

**構成要素**:
- ページタイトル: 「ログイン」（h2）
- フォーム:
  - メールアドレス入力欄（label + input）
  - パスワード入力欄（label + input + 表示/非表示切り替えアイコンボタン）
  - 「ログイン」ボタン（primary、幅100%）
- フッターリンク: 「アカウントをお持ちでない方は登録へ」→ `/signup`

**バリデーション**:
- メールアドレス: 必須・メール形式
- パスワード: 必須・8文字以上

**エラー表示**: フォーム上部にエラーメッセージ（error カラー）

---

### 3.3 アカウント登録画面（`/signup`）

**目的**: 新規ユーザー登録

**構成要素**:
- ページタイトル: 「アカウント登録」（h2）
- フォーム:
  - 名前入力欄
  - メールアドレス入力欄
  - パスワード入力欄（表示/非表示切り替えアイコンボタン付き）
  - パスワード確認入力欄（表示/非表示切り替えアイコンボタン付き）
  - 「登録する」ボタン（primary、幅100%）
- フッターリンク: 「すでにアカウントをお持ちの方はこちら」→ `/login`

**バリデーション**:
- 名前: 必須・1〜50文字
- メールアドレス: 必須・メール形式・重複チェック（サーバー側）
- パスワード: 必須・8文字以上・英数字混在推奨
- パスワード確認: パスワードと一致すること

**エラー表示**: 各フィールド下部にインラインエラー

---

### 3.4 ダッシュボード（`/dashboard`）

**目的**: ログインユーザーの活動サマリーを表示

**構成要素**:
1. **サマリーカード**（3カラム）
   - 総記録数
   - 今月の記録数
   - 最高評価（★5）の記録数

2. **カテゴリ分布**
   - ドーナツグラフ（または水平バーチャート）
   - 凡例付き

3. **最近の記録**（最新5件）
   - カード形式で一覧表示
   - 「すべて見る」→ `/logs`

4. **お気に入り**（rating ≥ 4 の記録 最新5件）
   - カード形式で一覧表示

---

### 3.5 飲酒記録一覧（`/logs`）

**目的**: 自分の全飲酒記録を閲覧・管理

**構成要素**:
1. **ページタイトル** + 「新しく記録する」ボタン（右上、primary）

2. **フィルターバー**
   - カテゴリ絞り込み（セレクトボックスまたはタブ）
   - 評価絞り込み（★1〜★5）
   - 日付範囲ピッカー

3. **記録グリッド**（PC: 3カラム、モバイル: 1カラム）
   - 各カード: サムネイル・お酒名・カテゴリバッジ・評価（★）・飲んだ日
   - クリックで詳細へ遷移

4. **ページネーション**

---

### 3.6 飲酒記録作成（`/logs/new`）

**目的**: 新しい飲酒記録を入力・保存

**構成要素**:
- ページタイトル: 「飲酒記録を追加」

**フォーム**:
| フィールド | UI コンポーネント | バリデーション |
|-----------|----------------|--------------|
| お酒の名前 | Input | 必須、最大100文字 |
| カテゴリ | Select | 必須 |
| 評価 | スター評価コンポーネント（★1〜★5） | 必須 |
| 飲んだ日 | Date Picker | 必須、未来日不可 |
| コメント | Textarea | 任意、最大1000文字 |
| 画像 | ファイルアップロード（プレビュー付き） | 任意、JPEG/PNG/WEBP, 2MB以内 |

- 「保存する」ボタン（primary）
- 「キャンセル」ボタン（ghost）→ `/logs` へ戻る

---

### 3.7 飲酒記録詳細（`/logs/$logId`）

**目的**: 1件の飲酒記録の詳細閲覧

**構成要素**:
- 戻るリンク: 「← 一覧へ戻る」
- 画像（登録済みの場合）
- お酒名（h2）
- カテゴリバッジ・評価（★）・飲んだ日
- コメント本文
- 「編集する」ボタン → `/logs/$logId/edit`
- 「削除する」ボタン（danger、確認ダイアログ付き）

---

### 3.8 飲酒記録編集（`/logs/$logId/edit`）

**目的**: 既存の飲酒記録を更新

**構成要素**:
- 記録作成フォームと同一構成（フィールドに既存値をプリセット）
- 「更新する」ボタン（primary）
- 「キャンセル」ボタン → `/logs/$logId` へ戻る

---

### 3.9 知識ベース カテゴリ一覧（`/knowledge`）

**目的**: お酒5カテゴリの一覧表示

**構成要素**:
- ページタイトル: 「お酒の知識を探す」（h1）
- カテゴリカードグリッド（PC: 3カラム、モバイル: 2カラム）
  - カード: カテゴリ画像・カテゴリ名・短い説明
  - クリックで `/knowledge/$category` へ遷移

---

### 3.10 カテゴリ詳細（`/knowledge/$category`）

**目的**: 特定カテゴリの詳細情報と銘柄一覧表示

**構成要素**:
1. **カテゴリヒーロー**
   - カテゴリ名（h1）・概要テキスト
   - カテゴリ画像

2. **詳細説明**
   - 歴史・製造方法・楽しみ方（リッチテキスト）

3. **代表銘柄一覧**（グリッド）
   - 各カード: 銘柄名・産地・アルコール度数・短い説明
   - クリックで `/knowledge/$category/$itemId` へ遷移

---

### 3.11 銘柄詳細（`/knowledge/$category/$itemId`）

**目的**: 特定銘柄の詳細情報表示

**構成要素**:
- 戻るリンク: 「← ${カテゴリ名} へ戻る」
- 銘柄名（h1）
- カテゴリバッジ・産地・アルコール度数
- 説明文
- テイスティングノート
- おすすめの飲み方
- 「この銘柄を記録する」ボタン → `/logs/new`（名前・カテゴリをクエリパラメータで引き渡し）

## 6. アクセシビリティ

- 全フォームに適切な `label` を設定
- ボタン・リンクは `aria-label` を付与
- カラーコントラスト比: WCAG AA 準拠（4.5:1 以上）
- キーボードナビゲーション対応

## 7. ルートファイル構成

```
apps/web/src/routes/
├── __root.tsx           # ルートレイアウト（ヘッダー・フッター）
├── index.tsx            # / トップページ
├── login.tsx            # /login ログイン
├── signup.tsx           # /signup 登録
├── dashboard.tsx        # /dashboard ダッシュボード
├── logs/
│   ├── index.tsx        # /logs 一覧
│   ├── new.tsx          # /logs/new 作成
│   └── $logId/
│       ├── index.tsx    # /logs/$logId 詳細
│       └── edit.tsx     # /logs/$logId/edit 編集
└── knowledge/
    ├── index.tsx        # /knowledge カテゴリ一覧
    └── $category/
        ├── index.tsx    # /knowledge/$category 詳細
        └── $itemId.tsx  # /knowledge/$category/$itemId 銘柄詳細
```

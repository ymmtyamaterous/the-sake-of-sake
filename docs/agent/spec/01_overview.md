# 全体概要仕様書

## 1. プロダクト概要

### 1.1 プロダクト名
**The sake of Sake**

### 1.2 プロダクト概要
お酒に関する「手帳」アプリ。ウイスキー・ビール・ワイン・日本酒・カクテルなどの基礎知識を閲覧できるとともに、ユーザーが実際に飲んだお酒を画像・コメント・評価と一緒に記録・管理できる Web アプリケーション。

### 1.3 ターゲットユーザー
- お酒を楽しむ成人ユーザー
- 飲んだお酒を振り返りたい人
- お酒の種類・知識を学びたい人

---

## 2. 機能一覧

### 2.1 認証・アカウント管理
| 機能 | 概要 |
|------|------|
| ユーザー登録 | メールアドレス・パスワードによるアカウント作成 |
| ログイン | メールアドレス・パスワードによるログイン |
| ログアウト | セッション終了 |
| プロフィール表示 | 登録名・メールアドレスの表示 |

### 2.2 お酒知識ベース（Knowledge Base）
| 機能 | 概要 |
|------|------|
| カテゴリ一覧 | ウイスキー / ビール / ワイン / 日本酒 / カクテルの5カテゴリ |
| カテゴリ詳細 | 各カテゴリの概要・製造方法・飲み方・代表的な銘柄など |
| 銘柄一覧 | カテゴリに紐づく代表的な銘柄・商品の一覧表示 |
| 銘柄詳細 | 銘柄ごとの産地・アルコール度数・テイスティングノートなど |

### 2.3 飲酒記録（Drink Log）
| 機能 | 概要 |
|------|------|
| 記録作成 | 飲んだお酒の名前・カテゴリ・評価・コメント・画像・飲んだ日を登録 |
| 記録一覧 | 自分の記録を日付降順で一覧表示（フィルタ・検索付き） |
| 記録詳細 | 個別記録の詳細閲覧 |
| 記録編集 | 既存記録の更新 |
| 記録削除 | 既存記録の削除 |

### 2.4 統計・ダッシュボード
| 機能 | 概要 |
|------|------|
| 記録数サマリー | 総記録数・今月の記録数 |
| カテゴリ分布 | 飲んだカテゴリ別の割合グラフ |
| お気に入り銘柄 | 高評価（★4以上）の記録一覧 |

## 4. システム構成

```
┌─────────────────────────────────────────────────────────┐
│                     Browser (SPA)                        │
│  React + TanStack Router + oRPC Client                   │
└──────────────────────┬──────────────────────────────────┘
                       │ HTTP / RPC over HTTP
┌──────────────────────▼──────────────────────────────────┐
│                  Hono Server (Bun)                        │
│  ├─ /api/auth/*        → better-auth handler             │
│  ├─ /rpc/*             → oRPC RPCHandler                 │
│  └─ /api-reference/*   → oRPC OpenAPIHandler             │
└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────┐
│                   SQLite (libsql)                         │
└─────────────────────────────────────────────────────────┘
```

### パッケージ構成
```
better-t-app/
├── apps/
│   ├── server/   # Hono サーバー
│   └── web/      # React SPA
└── packages/
    ├── api/      # oRPC ルーター定義
    ├── auth/     # better-auth 設定
    ├── config/   # 共通 tsconfig 等
    ├── db/       # Drizzle スキーマ・クライアント
    ├── env/      # 環境変数バリデーション
    └── ui/       # shadcn/ui コンポーネント集
```

## 5. 非機能要件

| 項目 | 要件 |
|------|------|
| 認証 | セッションベース（better-auth） |
| 画像保存 | サーバーのローカルファイルシステムに保存し、DB にはファイルパス（URL）を記録する |
| セキュリティ | OWASP Top 10 に準拠。SQL インジェクション対策として Drizzle ORM のプリペアードステートメントを使用 |
| アクセス制御 | 飲酒記録は作成者本人のみ閲覧・編集・削除可能 |
| レスポンシブ | PC / スマートフォン 両対応 |
| テスト | 各機能にユニットテストを実施 |

## 6. ページ構成（ルート）

| パス | 画面名 | 認証要否 |
|------|--------|---------|
| `/` | トップ（ランディング） | 不要 |
| `/login` | ログイン | 不要（未認証のみ） |
| `/signup` | アカウント登録 | 不要（未認証のみ） |
| `/dashboard` | ダッシュボード | 必要 |
| `/knowledge` | 知識ベース カテゴリ一覧 | 不要 |
| `/knowledge/$category` | カテゴリ詳細 | 不要 |
| `/knowledge/$category/$itemId` | 銘柄詳細 | 不要 |
| `/logs` | 飲酒記録一覧 | 必要 |
| `/logs/new` | 飲酒記録作成 | 必要 |
| `/logs/$logId` | 飲酒記録詳細 | 必要 |
| `/logs/$logId/edit` | 飲酒記録編集 | 必要 |
